# Enterprise Angular TypeScript Platform

## School ERP System

An Angular-based School Enterprise Resource Planning application.

## Features

- Dashboard
- Student Management
- Teacher Management
- Attendance Management
- Fees Management
- Settings

## Technology Stack

- Angular
- TypeScript
- HTML
- CSS
- Bootstrap

## Installation

```bash
npm install
```

## Run Application

```bash
ng serve
```

Open http://localhost:4200 in your browser.
